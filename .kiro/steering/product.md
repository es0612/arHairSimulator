# Product Overview

## ARヘアカラーシミュレーター (AR Hair Color Simulator)

An iOS mobile application that uses AR technology to allow users to virtually change their hair color in real-time. The app targets users aged 20-40 who are considering hair color changes, providing a stress-free beauty experience through high-precision AR simulation.

## Core Value Proposition

- **Risk-free experimentation**: Try different hair colors before visiting a salon or making permanent changes
- **Calm, stress-free experience**: Focused on providing a relaxing beauty experience with gentle design
- **High-precision AR simulation**: Natural-looking color blending using ARKit and depth information
- **Privacy-first approach**: All face processing happens locally on device

## Target Users

- Primary: Women and men aged 20-40 considering hair color changes
- Secondary: Beauty salon customers and hair stylists for consultation
- Use cases: Pre-salon consultation, personal experimentation, social sharing

## Key Features

- Real-time AR hair color simulation with 30+ fps performance
- 100+ hair colors organized by categories (Natural, Fashion, Pastel, Vivid, Gradient)
- Custom color creation with hue, saturation, brightness adjustments
- Before/after comparison with swipe gestures
- Save and share functionality (photos and short videos)
- Simulation history and favorites management
- Offline functionality for basic features
- Multi-language support (Japanese primary, English secondary)

## Business Model

- Freemium model with basic AR functionality free
- Premium subscription (¥500/month) for advanced features
- Future expansion: Professional salon version, beauty ecosystem integration
